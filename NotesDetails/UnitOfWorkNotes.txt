** Unit of work :
The unit of work pattern is a design pattern that allows you to group multiple operations into 
a single transaction. This is particularly useful in scenarios where you need to perform multiple 
database operations that should either all succeed or all fail together. 
The unit of work pattern helps manage the database context and ensures that changes are 
committed only when all operations are successful.
